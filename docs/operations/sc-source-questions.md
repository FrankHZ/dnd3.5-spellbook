# SC source-question review handoff

The current private review checklist is
`dice-qa/books/86/issue-416/dnd-review-checklist.zh-CN.md` in the configured
`DATA_REPO_PATH` repository. Its fixed delivery and bounded verification are
recorded in the [source-free report](../releases/v1.4/spell-compendium-source-question-handoff-report.md).
Use this checklist when preparing a user-directed review of the current
accepted reader notes. Earlier checklist and navigation files remain frozen
evidence; they do not describe the current final note set.

Each question is identified by `(targetId, questionId)`. Repeated short IDs in
different spells remain separate occurrences, and multiple questions in one
body have separate reply fields. The private binding index maps each occurrence
to the exact accepted name/body revisions, English input, source quotes,
printed/PDF pages and spans, complete context, and current Chinese note.

The checklist retains the original statements and separate project commentary.
Every question remains source-unresolved. A reply must identify its evidence and
source type; a reviewer's interpretation does not automatically become official
errata or authorize an accepted content change. Resolved questions and external
book/source-gap requests follow their existing workflows.

The private package's README documents root/package reproduction with explicit
code, data and existing runtime roots. Checks read fixed Git inputs and relevant
PDFs; they require no operator, app-state or rehearsal database. Sending the
checklist is a separate user decision. This handoff has not been sent externally.
